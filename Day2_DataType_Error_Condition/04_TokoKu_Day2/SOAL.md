# Proyek TokoKu - Day 2: Validasi Input dan Diskon

## Fitur baru
1. Harga dan jumlah divalidasi (tidak boleh huruf, tidak boleh nol).
2. Diskon: total >= 200.000 -> 15%, total >= 100.000 -> 10%, member tambah 5%.
3. Pajak 11% dari total setelah diskon.
4. Struk menampilkan tanggal dan jam transaksi.

# Latihan 2.3 - Create a Rock, Paper, Scissors Game

## Aturan
- batu mengalahkan gunting, gunting mengalahkan kertas, kertas mengalahkan batu

## Langkah
1. Komputer memilih acak dengan `random.choice`.
2. Pemain mengetik pilihan. Validasi: hanya `batu`, `kertas`, `gunting`.
3. Tentukan hasil dengan `if`, `elif`, `else` dan operator `and`, `or`.
4. Tampilkan MENANG, KALAH, atau SERI.

## Tantangan
- Terbaik dari 3 ronde.
- Terima singkatan `b`, `k`, `g`.

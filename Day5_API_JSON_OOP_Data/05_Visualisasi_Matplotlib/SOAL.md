# Latihan 5.5 - Grafik Penjualan Sederhana

Buat **satu grafik batang** yang membandingkan total penjualan setiap cabang.

1. Baca data dari `../data/penjualan_tokoku.csv`.
2. Hitung total penjualan dengan mengelompokkan data berdasarkan cabang.
3. Buat grafik menggunakan `plt.bar()`.
4. Tambahkan judul dan nama pada sumbu.
5. Simpan grafik sebagai `output/omzet_cabang.png`.

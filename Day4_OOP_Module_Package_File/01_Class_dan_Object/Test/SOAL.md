# Latihan 4.1B - Pesanan Sederhana

**Kasus:** Buat satu object pesanan yang menyimpan nama menu, harga, dan jumlah. Object dapat menghitung total harga pesanannya.

## Langkah
1. Buat class `Pesanan`.
2. Buat `__init__()` yang menerima `nama_menu`, `harga`, dan `jumlah`, lalu simpan sebagai attribute object.
3. Buat method `hitung_total()` yang mengembalikan hasil perkalian harga dan jumlah.
4. Buat satu object pesanan Kopi Susu Aren sebanyak 2, lalu tampilkan nama menu, jumlah, dan totalnya.

Fokus latihan ini pada class, object, attribute, method, dan `self`. Belum perlu menggunakan list atau loop.

## Target
```
Pesanan: Kopi Susu Aren x2
Total  : Rp 50.000
```

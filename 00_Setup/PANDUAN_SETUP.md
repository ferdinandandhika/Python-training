# Panduan Setup (kerjakan sebelum atau di awal Day 1)

## 1. Install Python
- Unduh dari https://www.python.org/downloads/ (versi 3.11 atau lebih baru).
- **Windows: centang `Add python.exe to PATH`** sebelum klik Install Now.
- Cek di terminal: `python --version`

## 2. Install Visual Studio Code
- Unduh dari https://code.visualstudio.com/
- Buka VS Code > ikon Extensions (Ctrl+Shift+X) > install **Python** (Microsoft).
- Opsional: install **GitHub Copilot** bila peserta punya lisensi.

## 3. Buka folder training
- VS Code > File > Open Folder > pilih folder `Python_Training_5_Hari`.
- Buka terminal: Terminal > New Terminal (Ctrl+`).

## 4. Pilih interpreter
- Ctrl+Shift+P > ketik `Python: Select Interpreter` > pilih Python 3.11+ atau `.venv`.

## 5. Jalankan cek
```
python 00_Setup/cek_setup.py
```
Semua baris harus bertanda OK. Library Day 5 boleh belum terpasang di Day 1.

## Rencana cadangan
Bila laptop tidak boleh install software:
- GitHub Codespaces (butuh akun GitHub), atau
- https://www.online-python.com/ untuk Day 1 sampai Day 3.

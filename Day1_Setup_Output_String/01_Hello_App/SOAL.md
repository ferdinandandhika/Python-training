# Latihan 1.1 - Create and Run a Python Application

**Kasus:** Kamu baru bergabung sebagai developer di toko kopi *TokoKu*.
Tugas pertamamu: buat aplikasi yang menampilkan kartu identitas toko.

## Langkah
1. Buka `latihan.py`.
2. Isi variabel nama toko, alamat, jam buka, dan telepon.
3. Tampilkan kartu identitas dengan `print()`.
4. Jalankan: klik tombol **Run** di kanan atas atau ketik `python latihan.py`.
5. Bonus: minta GitHub Copilot membuat garis pembatas dengan komentar
   `# buat garis pembatas sepanjang 40 karakter`.

## Target output
```
========================================
              KOPI TOKOKU
========================================
Alamat   : Jl. Merdeka No. 10, Bandung
Jam buka : 08.00 - 22.00
Telepon  : 022-1234567
========================================
```

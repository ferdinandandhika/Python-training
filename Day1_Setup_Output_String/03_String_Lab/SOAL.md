# Latihan 1.3 - Working with Strings

**Kasus:** Data pelanggan yang diketik kasir berantakan.
Rapikan setiap data memakai method string.

## Tugas (kerjakan berurutan di latihan.py)
1. Rapikan nama: `"   bUDi   santoso "` menjadi `Budi Santoso`.
2. Rapikan email: `"  BUDI.Santoso@Mail.COM "` menjadi `budi.santoso@mail.com`.
3. Ambil username dari email (sebelum `@`).
4. Format nomor HP `"081234567890"` menjadi `0812-3456-7890`.
5. Pecah kode pesanan `"ORD-2026-BDG-0042"` menjadi tahun, kota, dan nomor.
6. Format angka `1250000` menjadi `Rp 1.250.000`.
7. Format diskon `0.15` menjadi `15%`.
8. Sensor nomor kartu `"4111222233334444"` menjadi `************4444`.

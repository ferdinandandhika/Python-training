# Latihan 1.2 - Create a Personalized Greeting

**Kasus:** Kasir TokoKu ingin layar sapaan untuk pelanggan.

## Langkah
1. Minta input nama, kota asal, dan minuman favorit.
2. Rapikan nama dengan `.strip().title()`.
3. Tampilkan sapaan personal memakai f-string.
4. Tulis komentar di setiap bagian kode.

## Contoh jalan
```
Siapa nama kamu? andi pratama
Dari kota mana? bandung
Minuman favorit? kopi susu

Halo, Andi Pratama dari Bandung!
Hari ini kopi susu spesial untukmu.
Nama kamu terdiri dari 11 huruf.
```

# Proyek TokoKu - Day 1: Struk Sederhana

Hari ini TokoKu masih bisa menjual **satu item** per transaksi.

## Fitur
1. Input nama pelanggan, nama menu, harga, dan jumlah.
2. Hitung total.
3. Cetak struk rapi dengan format Rupiah.

## Contoh
```
==============================
         STRUK TOKOKU
==============================
Pelanggan : Rina
Menu      : Kopi Susu Aren
Harga     : Rp 25.000
Jumlah    : 3
------------------------------
TOTAL     : Rp 75.000
==============================
     Terima kasih, Rina!
```
Simpan hasilmu. Besok file ini dikembangkan lagi.

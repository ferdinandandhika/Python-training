# Latihan 3.3 - Kalkulator Sederhana dengan Function

Buat program kalkulator sederhana menggunakan beberapa function.

## Ketentuan

1. Buat function `tambah(a, b)`.
2. Buat function `kurang(a, b)`.
3. Buat function `kali(a, b)`.
4. Buat function `bagi(a, b)`. Jika `b` bernilai 0, tampilkan pesan bahwa angka tidak bisa dibagi nol.
5. Buat menu pilihan operasi.
6. Program terus berjalan sampai user memilih `5` untuk keluar.

## Menu

```text
1. Tambah
2. Kurang
3. Kali
4. Bagi
5. Keluar
```

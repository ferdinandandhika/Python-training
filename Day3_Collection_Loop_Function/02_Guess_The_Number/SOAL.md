# Latihan 3.2 - Create a Guess the Number Game

1. Komputer memilih angka acak 1 sampai 100, pemain punya 7 kesempatan.
2. Setiap tebakan diberi petunjuk terlalu kecil atau terlalu besar.
3. Ketik `menyerah` untuk berhenti (`break`).
4. Input bukan angka tidak mengurangi kesempatan (`continue`).

Diskusi: kenapa memakai `while`? Strategi apa yang selalu menang dalam 7 tebakan?

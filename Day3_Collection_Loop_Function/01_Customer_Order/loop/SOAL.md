# Latihan 3.1A - Mengenal Loop `for`

**Kasus:** TokoKu ingin menampilkan nomor antrean dari 1 sampai 5. Gunakan loop `for` agar tidak perlu menulis perintah `print()` berulang kali.

## Langkah
1. Gunakan `for` bersama `range(1, 6)`.
2. Pada setiap pengulangan, tampilkan nomor antrean.

**Catatan:** `range(1, 6)` menghasilkan angka 1 sampai 5; angka batas akhir tidak ikut ditampilkan. Latihan ini fokus pada `for` dan `range`, belum menggunakan list.

## Target
```
Nomor antrean: 1
Nomor antrean: 2
Nomor antrean: 3
Nomor antrean: 4
Nomor antrean: 5
```

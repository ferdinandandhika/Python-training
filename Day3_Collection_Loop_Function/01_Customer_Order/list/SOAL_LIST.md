# Latihan 3.1B - Mengenal List

**Kasus:** Kasir memasukkan tiga nama menu dan menyimpannya ke dalam sebuah list.

## Langkah
1. Buat list kosong bernama `menu`.
2. Minta tiga nama menu dengan `input()`.
3. Tambahkan setiap nama ke list menggunakan `.append()`.
4. Tampilkan isi list.

Latihan ini fokus pada list dan `.append()`. Belum perlu menggunakan loop atau dictionary.

## Contoh
Masukan:
```
Nama menu 1: Kopi Susu Aren
Nama menu 2: Americano
Nama menu 3: Matcha Latte
```

Hasil:
```
Isi list: ['Kopi Susu Aren', 'Americano', 'Matcha Latte']
```

**Catatan:** Di Python, struktur untuk menyimpan beberapa nilai seperti ini disebut `list`.
